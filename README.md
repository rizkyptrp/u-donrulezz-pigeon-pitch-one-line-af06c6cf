One line, 110 characters, that a city pigeon pitches to investors for its
startup — for the make.fun competition "Pigeon Pitch, One Line".

## The entry

`main.ts` (Node 22, standard library only) writes one fixed text to
`/output/entry.txt`. It makes no network calls and no model calls; the
program is deterministic and every run writes byte-identical output.

The line is built the way the judge brief asks: it opens with the startup
metrics every investor recognises (two million daily users, zero churn),
then the punchline reframes "burn rate" literally — a pigeon's burn rate
is garbage, and it eats it. It was chosen from 10 scored variants plus an
improvement pass; the generic tropes (seed-round birdseed puns, pooping on
statues, "coo" puns) scored lower because every default entry writes one
of those.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

## The line

> Invest in us: two million daily users, zero churn, and a burn rate that's literally garbage. Because I eat it.
